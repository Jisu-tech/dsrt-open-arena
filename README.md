# DSRT Open Arena

**Independent LLM Amplification Platform**

DSRT Open Arena is a production-grade system designed to measurably improve the practical performance of existing large language models through a coordinated twelve-engine amplification runtime.

## Architecture

- **Frontend:** Next.js 14+ (App Router), TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes (Serverless + Edge)
- **Database:** Supabase PostgreSQL with Row-Level Security
- **Auth:** Supabase Auth
- **Storage:** Supabase Storage
- **Hosting:** Vercel
- **CI/CD:** GitHub Actions

## Product Modes

- **Work Mode:** Continuous AI workspace with DSRT amplification
- **War Mode:** Controlled comparison between direct and amplified model execution
